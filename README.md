# Как играть на сервере?

## 1. Вход и регистрация
- Зайдите с **рекомендованной версии 26.1.2**.
- Зарегистрируйтесь и пройдите проверку. Чтобы её пройти:
  - Поверните голову ровно в ту сторону, которую вас попросят.
  - Не двигайтесь и дождитесь окончания таймера.
  - Если таймер не идёт – попробуйте снова.

## 2. Лобби и диалог с Дэвидом
- Вы появитесь в лобби. Можете осмотреться.
- Пообщайтесь с **Дэвидом**:
  - Для выбора вариантов диалога используйте **колёсико мыши** (прокрутка).
  - Нажмите **пробел** для выбора, либо кликните по НПС **правой кнопкой мыши**.
- После диалога войдите в портал.

## 3. Спавн и Гайдер
- Вы попадёте на спавн.
- **Внимательно осмотрите локацию**, прочитайте голограммы.
- Поговорите с **Гайдером 0.3.2 Beta**.

## 4. Квесты и варпы
- Узнав всю нужную информацию, возьмите **первый квест** у **Дон Гона**.
- Все доступные варпы можно посмотреть командой `/warp`. На варпах стоят **Информаторы** (НПС), которые расскажут о локации.
- Введите `/rtp` – и приятной игры!

---

## 5. Мистика и тотемы
- Мистические явления не появляются сразу – подождите несколько часов игры.
- Чтобы ускорить процесс, добудьте предметы для создания тотемов.
- Как создать тотемы:
  - Пропишите `/mistika`.
  - Нажмите на **книжку в левом нижнем углу**.
  - Выберите пункт *"Открыть ссылку"* – вы перейдёте в документацию с демонстрацией тотемов.
- На данный момент доступны призывы **Лукаса** и **Херобрина**.
